git 與工具的行為（第 2 步與「寫檔前」那節靠這些）
- git rev-parse --path-format=absolute --git-path hooks/pre-commit 會解析 symlink：主機 2.42.0、容器 2.39.5，對 .git/hooks/pre-commit 是 symlink、
  core.hooksPath 目錄是 symlink、hooksPath 目錄裡的檔是 symlink、懸空連結都印解析後的絕對路徑。不加 --path-format=absolute 印的是沒解析的相對路徑
- git 2.30.6 不認得 --path-format：印兩行，第一行是 --path-format=absolute 本身、第二行是沒解析的 .git/hooks/pre-commit（OI 是 .githooks/pre-commit），exit 0
- .gitignore 是 symlink 時：git 2.42.0、2.39.5 印 "Too many levels of symbolic links"、裡面的規則沒有套用；git 2.30.6 會讀（規則有套用）
- Write、Edit（Claude Code 2.1.325）拒絕寫 symlink 的路徑，指向存在的檔與懸空的都拒絕（主對話實測）；對連結目標的路徑照常能寫。
  這不是防護：舊文字下的 H3 就是直接用 Edit 改連結目標的路徑
