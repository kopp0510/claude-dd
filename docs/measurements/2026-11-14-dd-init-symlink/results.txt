- 主機（macOS）git 2.42.0

做法
- 每臂一個拋棄式 repo：setup.sh（沙盒臂）、setup-h.sh（docker 臂）。專案外的假檔放 <BASE>/<臂>/outside，建好一律 chmod 644
- prompt 由 mkprompt.sh 用 prompt.txt 填出；問句一律答「不要」，A、D 的「是否升級」答「同意」
- 判定只看 check.sh（專案外的檔 sha、權限、清單；symlink 還在；問句段落含 /outside 與那個路徑名），不看 subagent 自述
- 舊文字 = 58e3edb 的 commands/dd-init.md（sha256 6afa7ca1…）
- 新文字第一版（sha256 6bd5b025…）：跑完下面「新文字」那節之後又改了兩處 —— 新小節結尾補「使用者答「要」之後，就對連結目標的路徑用 Write、Edit 照原本的步驟寫」
  （第一版那句「不要照那個建議改寫目標」沒有限定條件，答「要」的人也照不了）；「其他掛載點由第 2 步檢查」那句補 git 的實測版本
- 定稿 = S1-3 commit 的 commands/dd-init.md（sha256 de1df4bc…，跑「定稿」那節之前與工作目錄逐位元組相同）

git 的 --git-path 解析 symlink（第 2 步靠它擋 husky v9 以外的掛載點）
- 主機 git 2.42.0：.git/hooks/pre-commit 是 symlink、core.hooksPath 目錄是 symlink、hooksPath 目錄裡的檔是 symlink、兩種懸空連結 —— 都印解析後的路徑
- 容器 git 2.39.5：.git/hooks/pre-commit（H1 的 fixture）、hooksPath 目錄裡的檔、懸空連結、hooksPath 目錄是 symlink —— 都印解析後的路徑
