你是 8 步開發迴圈步驟 4（code-review）的主對話，但這次只負責派工，不查證。你自己不要讀任何檔、不要跑指令、不要審。

1. 用 Agent 工具**在同一則訊息裡平行**派**剛好 3 個**審查者：subagent_type "code-reviewer"、不帶 model 參數、effort "{EFFORT}"（三個都要帶這個 effort 參數），description 分別是 R1、R2、R3。
   每個的 prompt 只有下面這一句（原樣，不加別的話）：
   R1：先用 Read 讀完 {R1}，它就是你的完整任務說明，照裡面做。
   R2：先用 Read 讀完 {R2}，它就是你的完整任務說明，照裡面做。
   R3：先用 Read 讀完 {R3}，它就是你的完整任務說明，照裡面做。
2. 審查者在背景跑，通常要好幾分鐘。派出之後結束這一輪，它們交回時你會被喚醒。**等三個都回來**才往下。
   某個審查者失敗或沒回來：不補派、不重派。
3. 三個都回來之後，只回覆一行：`DONE R1=<交回了／失敗> R2=<…> R3=<…>`。不要貼報告、不要查證、不要評論（報告會從紀錄檔讀）。
